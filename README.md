## Ejercicio 1 - Ticket de un producto

### Descripción
Programa que calcula el subtotal, IVA y total
de una compra y muestra un ticket en consola.

### Cómo ejecutar
Desde la carpeta principal del proyecto:

```bash
node ejercicio-1/ticket.js
```
